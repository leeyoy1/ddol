# 동네 별자리 (ddol)

걸을 때마다 동네 하늘에 별이 하나씩 생기는 산책 놀이. 서울 안의 출발점에서 반경 안의 무작위 지점까지 가서 그 자리에서 모양을 그리고 돌아오면 별이 된다. 별 5개가 모이면 별자리가 된다.

- 모양: 도형(별·하트·네모·세모·동그라미) · 동물(물고기·고양이·토끼·고래) · 식물(나뭇잎·나무·튤립·꽃·선인장) · **내 그림**(올린 그림의 윤곽선. 그림은 저장하지 않고 윤곽 좌표만 폰에 남는다)
- 수집: 모양 도감(14종 + 내 도안마다 한 칸) · 업적 14개 · 동네 스탬프(도착한 동) · ✨ 반짝 원정(12번에 1번꼴). 모두 별 기록에서 다시 계산한다.
- 만들기: ✍️ 손가락으로 그린 도안·🖼️ 올린 그림을 도안집에 저장해 원정에 쓴다. 다녀온 원정은 지도 없이 걸은 모양만 담은 **작품 카드**(PNG)로 저장·공유한다.
- 지도에는 가는 길(파란 점선) → ✏️ 그리기 시작점 → 그릴 모양(빨간 선) → 돌아오는 길(회색 점선)이 나뉘어 보이고, 도착지 근처 장소 이름은 OpenStreetMap 역지오코딩(Nominatim)으로 찾는다(도착지 좌표만 보낸다).

- 경로 계산은 폰 브라우저 안에서 한다. 서버가 없다.
- 위치·걸은 길·별은 그 폰의 브라우저 저장소(localStorage)에만 남는다. 어디로도 보내지 않는다.
- 원정 GPX 파일에는 출발점이 들어 있다. 남에게 보내지 않는다.
- 배경 지도는 OpenStreetMap이고, 설정에서 V-World(국토교통부 공간정보 오픈플랫폼) 인증키를 넣으면 V-World 지도로 바꿀 수 있다.
